## Appendix: Technical Deep Dive

### Smart Contract Architecture

**domain-registry.clar (271 lines)**
```clarity
;; Core domain tokenization
(define-map domains
  { domain-id: uint }
  {
    name: (string-ascii 256),
    owner: principal,
    market-value: uint,  ;; In USDCx
    has-fractional: bool
  }
)
```

**fractional.clar (287 lines)**
```clarity
;; SIP-010 fungible token
(define-fungible-token domain-shares)

(define-public (transfer (amount uint) (recipient principal))
  (ft-transfer? domain-shares amount tx-sender recipient)
)
```

**marketplace.clar (342 lines)**
```clarity
;; Trading infrastructure
(define-constant trading-fee-bps u30)  ;; 0.3%

(define-public (buy-shares (listing-id uint) (shares uint))
  ;; Execute trade in USDCx
  (let ((fee (calculate-fee total-cost)))
    (ft-transfer? domain-shares shares seller buyer)
  )
)
```

### USDCx Integration Examples

**Valuation Display:**
```typescript
const formatUSDCx = (microUnits: number) => {
  const usdcx = microUnits / 1_000_000;
  return `${usdcx.toLocaleString()} USDCx`;

```
